# Privacy policy

Last updated: 18 November 2026.

"Hearth" is a private application run by one household for its own use. It is not offered to the public and has no other users.

**What it accesses.** When signed in to the household's own Google account, Hearth reads and writes files in that account's Google Drive, including Google Docs and Sheets, so the household's assistant can make, find and keep documents for the family.

**What it does with the data.** The data is used only to carry out what members of the household ask. It is kept on the household's own computer and in the household's own Google account. To answer a request, text from a document may be processed by the AI model services the household itself subscribes to; it goes nowhere else.

**Sharing.** Hearth does not sell, rent or share Google user data with anyone. It is not used for advertising, and it is not used to train any general model.

**Storage and removal.** Sign-in tokens are kept in an encrypted store on the household's own computer. Access can be removed at any time from the Google account's security page, which ends all access at once.

**Limited use.** Hearth's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

**Contact.** Questions can be raised through the issues page of this site's repository.
